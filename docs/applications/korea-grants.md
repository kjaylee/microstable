# Solana Foundation Korea Grants 신청서 초안 — Microstable

## 1) 프로젝트 개요

Microstable은 **AI 에이전트가 거버넌스에 참여하는 멀티 담보 스테이블코인 프로토콜**입니다.  
현재 Solana devnet에서 실제로 동작 중이며, 다음 구성요소를 공개 저장소로 운영하고 있습니다.

- 온체인 프로그램(Anchor/Rust)
- 오프체인 Rust Keeper(리스크 관리, 오라클 업데이트, 리밸런싱)
- Mission Control 대시보드(브라우저에서 Solana RPC 직접 조회)
- 공개 문서 및 보안 감사 리포트

목표는 단순 토큰 발행이 아니라, 한국 개발자들이 재사용할 수 있는 **스테이블코인 표준형 레퍼런스 구현**을 제공하는 것입니다.

## 2) 한국 생태계 기여 포인트

저는 한국 기반 개발자로서, Microstable을 통해 아래와 같은 로컬 기여를 만들고자 합니다.

1. **한국어 개발 문서 확장**  
   온보딩 문서, 운영 가이드, 아키텍처 설명을 한국어로 정리하여 신규 개발자 진입 장벽을 낮추겠습니다.

2. **실전형 레퍼런스 코드 제공**  
   Solana 스테이블코인 설계 시 필요한 프로그램 구조/오프체인 운영 패턴/보안 체크리스트를 코드와 함께 제공하겠습니다.

3. **커뮤니티 공유 세션 운영**  
   Superteam Korea 및 로컬 빌더 커뮤니티를 대상으로 구현/테스트/운영 노하우를 공유하여 실제 빌더 수를 늘리겠습니다.

## 3) 그랜트 기간 마일스톤 (제안: 8주)

### 마일스톤 1 (1–2주): 문서/온보딩 패키지 정비
- 한국어 개발자용 빠른 시작 가이드 완성
- 프로그램 + keeper 실행 절차 표준화
- 산출물: `docs/` 내 한국어 온보딩 문서, 체크리스트

### 마일스톤 2 (3–5주): SDK/표준화 레이어 공개
- 스테이블코인 핵심 플로우용 SDK 인터페이스 문서화
- 템플릿 예제(초기화, 민트, 상환, 상태 조회) 제공
- 산출물: 예제 코드 + 표준 인터페이스 명세

### 마일스톤 3 (6–8주): 커뮤니티 확산 및 피드백 반영
- 한국 개발자 대상 실습 세션/데모 진행
- 이슈/PR 기반 개선 반영
- 산출물: 세션 자료, 개선 릴리스 노트, 적용 사례 정리

## 4) 예산 사용 방향

지원금은 아래 항목에 집중하여 사용하겠습니다.

- 문서화 및 개발자 교육 자료 제작
- 테스트/검증 자동화 강화
- 운영 안정성 개선(모니터링/장애 대응 문서 및 툴링)

## 5) 기대 효과

- 한국 개발자가 Solana에서 스테이블코인을 구현할 때 참고할 수 있는 공개 표준 사례 확보
- 한국어 기반 학습 자료 축적으로 신규 빌더 온보딩 속도 향상
- 국내 팀들이 재사용 가능한 오픈소스 컴포넌트(코드/문서/운영 가이드) 제공

Microstable은 한국 개발자 커뮤니티가 "아이디어"를 넘어 "실제 배포 가능한 프로토콜"을 만들 수 있도록 돕는 기반 프로젝트가 되겠습니다.
